# Barrer Security Mesh VPN

### Enterprise-Grade Mesh VPN for Everyone

**Built from the [NetBird Open Source Project](https://github.com/netbirdio/netbird)**

---

## About This Fork

Barrer Security Mesh VPN is a fork of NetBird, enhanced with enterprise-level features and maintained under our mission: **Security shouldn't have a cost barrier.**

### Our Model
- ✅ **Velocity Enterprise users** get new features 1 month early
- ✅ **All features** become fully open source after 30 days
- ✅ **Everyone** gets enterprise-grade security, free to self-host
- ✅ **Development** funded by those who can afford it, benefiting everyone

### What We're Building
- Advanced enterprise management features
- Enhanced security capabilities
- Seamless integration with Velocity ecosystem
- Professional support for enterprise users
- Community-driven development

We believe enterprise-level network security should be accessible to everyone - small businesses, schools, nonprofits, hobbyists. Not just those who can afford $20/user/month.

This fork brings Tailscale/NetBird Enterprise-level features to the community while maintaining a sustainable business model that funds continued development.
